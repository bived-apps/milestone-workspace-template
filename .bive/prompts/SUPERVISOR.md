# Retired agent supervisor role

This compatibility pointer grants no authority. Use [ADVISOR.md](ADVISOR.md) and its project additions instead.
Do not load legacy `project/SUPERVISOR.md` additions as current instructions: the coordinator must review and migrate
them with the owner, removing any supervisory powers. Only the human owner authorizes work and merges, merges or
closes pull requests, approves teams and gates, and releases tests. No agent qualification grants these powers.

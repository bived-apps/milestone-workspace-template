# Project additions to the role prompts

Bive's role prompts (`../SUPERVISOR.md`, `../COORDINATOR.md`, `../DELEGATE.md`) are inviolable: nobody edits them in a
project. To add to a role, the supervisor or the coordinator writes `<ROLE>.md` here (e.g. `DELEGATE.md`); an agent
reads it right after its role prompt. An addition may narrow or detail a rule, never loosen or contradict one: where
they differ, the core prompt wins. Delegates never change this folder either.
